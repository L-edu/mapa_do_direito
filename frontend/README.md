# Mapa do Direito — front-end (React + Vite)

Interface da Sprint 2. Consome a API FastAPI da raiz do repositório.

```powershell
npm install
copy .env.example .env     # opcional
npm run dev                # http://localhost:5173
npm run build              # gera dist/ (verifica a compilação)
```

A API precisa estar em execução (padrão `http://localhost:8000`, configurável em `VITE_API_URL`).
Documentação completa, contas de demonstração e mapa de telas/endpoints: veja o `README.md` da raiz.
